## 📂 Proyectos destacados

### 📋 App Tareas - Sistema de Gestión y Recordatorios


Sistema web de gestión de tareas desarrollado con **React + Vite + Supabase** que permite organizar tareas, programar recordatorios automáticos por correo electrónico y autenticarse mediante **Magic Links**.

### Características destacadas del sistema:

-Diseño responsive para diferentes dispositivos: celulares, tablets o PC.

-Sistema de login con Magic Links configurado con SMTP propio, usando la API de Gmail, Netlify Functions y Edge Functions de Supabase.

-Una vez creada una tarea, es posible enviarla como notificación a tu dirección de correo electrónico. Para ello, hay dos opciones:

1-Envío inmediato

2-Puedes programar un envío programado para más tarde (el sistema revisa la tabla de notificaciones programadas cada 1 minuto). Para desarrollarlo, he usado cron-job.org, Edge Functions de Supabase y API de Gmail. Esta última funcionalidad solo funciona en Argentina, ya que los servidores están configurados en UTC-3.

Puedes probar el sistema haciendo clic en este link:

🔗 **Demo:** https://sistema-tareas-recordatorios.netlify.app

Para mas información este es el enlace al repositorio:

**Repositorio:** https://github.com/franco497/App-tareas-react-supabase

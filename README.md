## 📂 Proyectos destacados

### 📋 App Tareas — Sistema de Gestión y Recordatorios

Aplicación web desarrollada con **React, Vite y Supabase** para la gestión de tareas, autenticación y envío de recordatorios automáticos por correo electrónico.

### Características principales

- Diseño responsive para celulares, tablets y PC.
- Autenticación mediante Magic Links.
- Integración con SMTP y API de Gmail.
- Uso de Netlify Functions y Edge Functions de Supabase.
- Envío inmediato de notificaciones por correo electrónico.
- Programación de recordatorios automáticos.
- Procesamiento de notificaciones programadas mediante tareas automáticas.
- Integración con cron-job.org.
- Interfaz adaptada a diferentes dispositivos.

🔗 **Demo:** https://sistema-tareas-recordatorios.netlify.app

🔗 **Repositorio:** https://github.com/franco497/App-tareas-react-supabase
